# C001. 📄 C File Extensions

| Extension | Purpose                                                    |
| --------- | ---------------------------------------------------------- |
| `.c`      | C source code file                                         |
| `.h`      | Header file  — to declare functions, macros, structs, etc. |

---

## ✅ Example in C

```c
// main.c
#include "myheader.h"

int main() {
    sayHello();
    return 0;
}
```

```c
// myheader.h
void sayHello();
```
